# API_calling_and_agents

This project contains a hands-on Jupyter notebook for learning how to call an LLM API and build simple agent behavior from first principles.

## Notebook

- `api_calls_agents.ipynb`

## Topics covered

- OpenRouter setup and configuration
- OpenAI-compatible API usage
- Model inference with prompt and completion calls
- Temperature and output randomness
- Stateless multi-turn chat patterns
- Function/tool calling basics
- Simple agent loops that reason and act in steps

## Prerequisites

- Python environment with Jupyter or Google Colab
- An OpenRouter API key stored as `OPENROUTER_API_KEY`

## How to use

1. Open the notebook in Jupyter or Colab.
2. Add your OpenRouter API key.
3. Run the cells from top to bottom in order.

This notebook is designed as an introductory walkthrough for API-driven LLM usage and agent-style workflows.
